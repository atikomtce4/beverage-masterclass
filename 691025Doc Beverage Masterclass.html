2. 🛠️ สร้างสูตรด้วย Builder

🎯 เป้าหมาย

สร้างไฟล์ Master JSON ที่มีข้อมูลครบถ้วน ทั้งภาษาไทย/อังกฤษ รูปภาพ และขั้นตอนการทำงาน

📝 วิธีทำ

1 เปิด Builder

เปิดไฟล์ web-builder.html ใน Browser (Chrome/Edge/Firefox)

2 กรอกข้อมูลพื้นฐาน (แท็บ 1)
ฟิลด์ คำอธิบาย ตัวอย่าง
Recipe ID ชื่อไฟล์ (ไม่มี .json) roselle_10L
Category หมวดหมู่ herbal
Icon ไอคอนแสดงหน้าเว็บ 🌺
Base Volume ปริมาณเริ่มต้น 10 (ลิตร)
Total Time เวลารวมทั้งหมด 163 นาที
Target Temp อุณหภูมิหลัก 95 °C
3 กรอกข้อมูลรายละเอียด (แท็บ 2)

กรอกข้อมูล 2 ภาษา (TH/EN) ให้ครบ: ชื่อสูตร, คำนำ, สรรพคุณ, คำเตือน, เวลาเตรียม/ทำ, ข้อมูลโภชนาการ

4 เพิ่มวัตถุดิบ (แท็บ 3)

กด "+ เพิ่มวัตถุดิบ" แล้วกรอกชื่อ (TH/EN), ปริมาณ + หน่วย, ติ๊ก Scalable ถ้าต้องการให้ปรับตามปริมาณ

5 เพิ่มขั้นตอนทำเอง (แท็บ 4)

กด "+ เพิ่มขั้นตอนทำเอง" แล้วกรอก Title, Description (ใช้ {key} แทนตัวแปร), Image path, Tips, Desc Variables

6 เพิ่มขั้นตอนเครื่อง (แท็บ 5)

กด "+ เพิ่มขั้นตอนเครื่อง" แล้วกรอก Function, Target Value + Unit, Duration + Timeout, Outputs, Title/Description

💡 เคล็ดลับ

ใช้ปุ่ม 📥 Import JSON เพื่อดึงข้อมูลจากไฟล์ FML ที่มีอยู่แล้ว แล้วค่อยแก้ไข จะประหยัดเวลามาก!

7 Export ไฟล์

กดปุ่ม 🌐 Export Web JSON → ได้ไฟล์ roselle_10L.json

3. 📦 อัปโหลดขึ้น GitHub

🎯 เป้าหมาย

นำไฟล์ Master JSON ไปเก็บไว้บน GitHub Pages เพื่อให้ Web Viewer ดึงไปใช้ได้

📝 วิธีทำ

วิธีที่ 1: ผ่าน GitHub Web UI

  1. ไปที่ github.com/yourusername/BeverageSystem
  2. ไปที่โฟลเดอร์ recipes/herbal/
  3. กด "Add file" → "Upload files"
  4. ลากไฟล์ roselle_10L.json ลงไป
  5. กด "Commit changes"

วิธีที่ 2: ผ่าน Git Command Line

# เพิ่มไฟล์
git add recipes/herbal/roselle_10L.json

# Commit
git commit -m "Add roselle 10L recipe"

# Push
git push origin main

✅ ตรวจสอบ

  1. รอ 1-2 นาทีให้ GitHub Pages deploy
  2. เปิด https://yourusername.github.io/BeverageSystem/
  3. ตรวจสอบว่าสูตรปรากฏในหน้าเว็บ

4. 🌐 ดูสูตรบน Web

🎯 เป้าหมาย

ดูสูตรที่อัปโหลดไว้ ปรับปริมาณ และ Copy JSON ไปใช้กับ ESP32

📝 วิธีทำ

1 เปิดหน้าสูตร

ไปที่ https://yourusername.github.io/BeverageSystem/ → เลือกหมวดหมู่ → คลิกที่สูตร

2 ปรับปริมาณ

ใช้ Slider หรือกดปุ่ม Preset (1L, 2L, 5L, 10L, 15L, 20L)

  • ✅ วัตถุดิบจะปรับตามปริมาณ
  • ✅ ขั้นตอนเครื่องจะปรับ Target ตาม
  • ✅ เวลาต้ม/สกัดจะไม่เปลี่ยน (คงที่)
3 Copy JSON ไป ESP32

โหมด Machine (🤖 ใช้เครื่อง):

  1. กดปุ่ม "📋 คัดลอกสูตรเข้าเครื่อง (XL)"
  2. ระบบจะ Copy JSON ที่ Scale แล้วลง Clipboard
  3. ไปที่หน้า ESP32 → Paste → บันทึก

5. 🤖 Import ลง ESP32

🎯 เป้าหมาย

นำสูตรจาก Web ไปเก็บไว้ใน ESP32 เพื่อใช้งาน

📝 วิธีทำ

1 เข้าหน้า ESP32

เชื่อมต่อ WiFi กับ ESP32 → เปิด Browser → เข้า http://192.168.4.1/

2 Import สูตร
  1. กดปุ่ม "➕ สร้างสูตรใหม่"
  2. กดปุ่ม "📥 Import"
  3. Paste JSON ที่ Copy จาก Web
  4. กด "💾 บันทึกสูตร"
3 ตรวจสอบ

สูตรจะปรากฏในรายการ → คลิกเพื่อดูรายละเอียด → กด "▶️ เริ่มทำงาน" เพื่อรันสูตร

6. ✏️ การแก้ไขสูตร

🎯 เป้าหมาย

แก้ไข Master JSON ที่มีอยู่แล้ว

📝 วิธีทำ

1 Download ไฟล์เดิม

ไปที่ GitHub → คลิกที่ไฟล์ → กดปุ่ม "Raw" → กด Ctrl+S เพื่อดาวน์โหลด

2 Import เข้า Builder

เปิด web-builder.html → กดปุ่ม "📥 Import JSON" → ระบบจะ Auto-Detect และโหลดข้อมูลทั้งหมด

3 แก้ไขและ Export

แก้ไขข้อมูลที่ต้องการ → กด "🌐 Export Web JSON" → อัปโหลดขึ้น GitHub (ทับไฟล์เดิม)

7. 🔧 Troubleshooting

❌ เปิด Builder แล้ว Error

สาเหตุ: Browser ไม่รองรับ JavaScript บางฟีเจอร์

วิธีแก้: ใช้ Chrome/Edge/Firefox เวอร์ชันล่าสุด

❌ Import JSON แล้ว Error "Cannot read properties of undefined"

สาเหตุ: ไฟล์ JSON ผิด format

วิธีแก้:

  1. ตรวจสอบว่าเป็น JSON ที่ถูกต้อง (ใช้ JSON Validator)
  2. ตรวจสอบว่ามี field ที่จำเป็นครบถ้วน
  3. ลอง Import ใหม่
⚠️ Web ไม่แสดงสูตรที่อัปโหลด

สาเหตุ: GitHub Pages ยังไม่ deploy

วิธีแก้:

  1. รอ 1-2 นาที
  2. กด Ctrl+F5 เพื่อล้าง Cache
  3. ตรวจสอบว่าไฟล์อยู่ในโฟลเดอร์ที่ถูกต้อง
⚠️ ESP32 Import แล้วไม่ทำงาน

สาเหตุ: JSON ที่ Copy มาไม่สมบูรณ์

วิธีแก้:

  1. ตรวจสอบว่า Copy JSON ครบถ้วน (ไม่มีตัดขาด)
  2. ตรวจสอบว่า ESP32 มีพื้นที่ว่างพอ
  3. ลอง Paste ใหม่
ℹ️ ค่า Target ไม่เปลี่ยนเมื่อปรับปริมาณ

สาเหตุ: Field scalable ตั้งค่าเป็น false

วิธีแก้: เปิด Master JSON → ตรวจสอบว่า scalable: true ในขั้นตอนที่ต้องการให้ปรับ → Export ใหม่

8. ❓ FAQ

Q: สามารถใช้ Builder แบบ Offline ได้ไหม?

A: ได้ครับ Builder เป็น HTML ไฟล์เดียว รันบน Browser ได้เลย ไม่ต้องต่ออินเทอร์เน็ต

Q: สามารถเพิ่มภาษาอื่น besides TH/EN ได้ไหม?

A: ได้ครับ แต่ต้องแก้โค้ดใน app.js และ web-builder.html ให้รองรับภาษาที่ 3

Q: ESP32 สามารถเก็บสูตรได้กี่สูตร?

A: ขึ้นอยู่กับรุ่นของ ESP32 และขนาดของสูตร โดยทั่วไปเก็บได้ 20-50 สูตร

Q: สามารถ Export สูตรเป็น PDF ได้ไหม?

A: ยังไม่มีฟีเจอร์นี้ในเวอร์ชันปัจจุบัน แต่สามารถเพิ่มได้ใน Phase ถัดไป

Q: ถ้า GitHub ล่ม จะใช้งานไม่ได้ไหม?

A: ถ้า ESP32 มีสูตรที่ Import ไว้แล้ว ยังใช้งานได้ครับ แต่ถ้าต้องการสูตรใหม่ ต้องรอ GitHub กลับมา

Q: สามารถใช้ Local Server แทน GitHub ได้ไหม?

A: ได้ครับ ใช้ Python Simple HTTP Server:

cd BeverageSystem
python -m http.server 8000

แล้วเปิด http://localhost:8000/

✅ จุดแข็ง

  • Architecture แยก Master JSON ออกจาก FML JSON ชัดเจน
  • MVP Thinking ตัดฟีเจอร์ที่ไม่จำเป็นออก
  • UX ลื่นไหล ใช้ Clipboard แทนการดาวน์โหลด
  • Data Structure ยืดหยุ่น ด้วย scalable flag

⚠️ จุดเสี่ยง

  • High ESP32 ต้อง Fetch จาก GitHub (HTTPS, CORS, RAM)
  • Medium ไม่มี Version Control ของสูตร
  • Medium Clipboard Workflow อาจไม่สะดวกสำหรับบางคน
  • Low Error Handling ยังไม่ครอบคลุม
